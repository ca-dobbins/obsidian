### How to take one
Suppose we know $f'(x)=3x^{2}$. What was $f(x)$? Well, $f_{1}(x)=x^{3}$ works. $f_{2}(x)=x^{3}+1$ also works. 

So, $F(x)=x^{3}+C$ works for all constants $C$. We say that $F(x)$ is the most general antiderivative of $f'(x)$.

| Derivative                   | General Antiderivative   |
| ---------------------------- | ------------------------ |
| $kf(x)$                      | $kF(x)+C$                |
| $f(x)\pm g(x)$               | $F(x)\pm G(x)+C$         |
| $x^n$ ($n\neq-1$)            | $\frac{1}{n+1}x^{n+1}+C$ |
| $\frac{1}{x}$                | $\ln \|x\|+C$            |
| $e^x$                        | $e^x+C$                  |
| $b^x$, $b>0$                 | $\frac{1}{\ln b}b^x+C$   |
| $\cos x$                     | $\sin x+C$               |
| $\sin x$                     | $-\cos x+C$              |
| $\sec ^{2}x$                 | $\tan x+C$               |
| $\sec x\tan x$               | $\sec x+C$               |
| $\csc x\cot x$               | $\csc x+C$               |
| $\csc ^{2}x$                 | $-\cot x+C$              |
| $\frac{1}{\sqrt{ 1-x^{2} }}$ | $\arcsin x+C$            |
| $\frac{1}{1}$                |                          |
