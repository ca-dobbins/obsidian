### Inc/Dec Test
*subtitle*

***Def***: A function $f(x)$ is increasing on an interval I if $f(x_{1})<f(x_{2})$ when $x_{1}<x_{2}$ on I. Similarly for decreasing.

***Inc/Dec Test***: A function $f$ is increasing on an interval if $f(x)>0$ for all x in that interval. It's decreasing on an interval if $f(x)<0$ for all x on the interval.

### Concavity
*subtitle*

***Def***: If the graph of $f$ lies above all of it's tangent lines on an interval, then $f$ is concave upwards on the interval. Similarly for concave downwards.

***Concavity Test***: A function $f$ is concave upwards on an interval if $f''>0$ on that interval. It is concave downwards on an interval if $f''<0$ on that interval.

***Inflection Point***: A point $P$ on $y=f(x)$ is an inflection point of $f$ if the concavity changes at that point. i.e. $f''(x)=0$.
