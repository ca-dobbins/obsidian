### Building Blocks
*the meat of limits*

***Identity:*** 
$$
\lim_{ x \to a } x=a
$$
***Constant:***
$$
\lim_{ x \to a } c=c
$$
***Major Limit Laws***
Suppose:
$$
\lim_{ x \to a } f(x)=L \quad\text{and}\quad \lim_{ x \to a } g(x)=M
$$
1. *Sum*:
$$
\lim_{ x \to a } [f(x)+g(x)]=\lim_{ x \to a } f(x)+\lim_{ x \to a } g(x)
$$
2. *Product*:
$$
\lim_{ x \to a } [f(x)g(x)]=\lim_{ x \to a } f(x) \times \lim_{ x \to a } g(x)
$$
3. *Constant Multiple*:
$$
\lim_{ x \to a } cf(x)=c\lim_{ x \to a } f(x)
$$
4. *Difference*:
$$
\lim_{ x \to a } f(x)-g(x)=\lim_{ x \to a } f(x)\,-\lim_{ x \to a } g(x)
$$
5. *Quotient*:
